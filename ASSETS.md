# Asset credits

## Animated player

`assets/robot-expressive.glb` is the RobotExpressive model from the
[Three.js examples repository](https://github.com/mrdoob/three.js/tree/r170/examples/models/gltf/RobotExpressive).

- Source: Three.js r170
- License: MIT
- Local copy: `assets/robot-expressive.glb`

The game loads this file locally with `GLTFLoader`, so it does not depend on a
third-party asset request while players are running the game.
